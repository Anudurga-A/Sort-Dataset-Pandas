# Sort Dataset using Python and Pandas

## Objective
To learn how to sort datasets using numerical and categorical columns with Python Pandas.

## Tasks Completed
- Sort values in ascending order.
- Sort values in descending order.
- Sort datasets using multiple columns.

## Tools Used
- Python
- Pandas
- VS Code / Jupyter Notebook

## Outcome
Learned how to organize and analyze datasets using ascending, descending, and multiple-column sorting techniques.
